# Design

Surface: citizen intake + clerk `/guichet`. Mode: Operate on forms, Persuade only on the two doors.

## Scene

A greffe counter under cool tube light. The object is a **carnet à souche**: two copies, a perforation, a stamped number. Not a Ministry portal. Not a SaaS landing.

## Thesis

Refuse the two equal feature cards. The first viewport is one sheet torn in two: **Parler** above the perforation, **Obtenir un acte** below.

## Palette

Restrained. Cool duplicate paper, not cream.

- Paper: `#E6EAEE`
- Ink: `#15202B`
- Stamp: `#24399A` (tampon encreur)
- Tape: `#F3E100` on ink (legal strip)
- Clerk green: `#1F4D3A` only on `/guichet`

## Type

- Body: Atkinson Hyperlegible (public-sector legibility)
- Ticket codes: Archivo Narrow

## Motion

One moment: the tracking code stamps onto the souche after submit.

## Ban

Ministry flag tricolor as chrome. Jokko lookalikes. Inter + purple gradient. Silent guest sessions.
